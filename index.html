rclone-backup

A personal Google Drive integration used with rclone to back up files from the owner's server to the owner's Google Drive account.

What the application does

The owner runs rclone on their own computer or server and authorizes access through Google's sign-in page. Files transfer directly from the computer or server to Google Drive. This website describes the integration; it does not receive backup files or handle Google sign-in.

Google Drive access

The integration is configured to use the drive.file permission, which allows access to files created by the application or explicitly made available to it. This supports creating backup folders, uploading files, and checking or managing those backups.

Personal use

This integration is intended for the owner's personal use. It is not a public file-storage service and is not an official Google or rclone product.
