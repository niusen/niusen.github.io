Privacy Policy

rclone-backup · Updated October 27, 2026

Purpose and operator

rclone-backup is a personal backup integration maintained by GitHub user niusen. It uses rclone to transfer the owner's chosen files to the owner's Google Drive account.

Data accessed and used

The integration uses Google's drive.file authorization scope. It can access files it creates and files explicitly made available to it. File contents and metadata, such as names, sizes and modification times, are used to upload, list, compare and manage backup files.

OAuth authorization tokens are stored in rclone's configuration on the devices where the owner configures it. They permit the authorized rclone installation to access Google Drive. This website does not collect passwords, authorization tokens or backup files.

Storage and sharing

Backup files are stored in the owner's Google Drive account. Configuration and any operational logs remain on the devices where rclone runs. Google processes data under its own terms and privacy policy. The operator does not sell Google user data, use it for advertising, or use it to train generalized AI or machine learning models.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls how long backups and logs are kept. Backup files can be deleted through Google Drive, including removal from its trash as appropriate. Access can be revoked in the Google Account's third-party connections settings. Revoking access does not itself delete uploaded backups. Local rclone configurations and logs can be removed from the devices where they are stored.

This website

These pages do not include analytics, advertising, sign-in forms or application cookies. The site is hosted on GitHub Pages; GitHub may process request information under the GitHub Privacy Statement.

Contact and changes

The operator's public contact profile is github.com/niusen. This policy will be updated if the integration's handling of data changes.
